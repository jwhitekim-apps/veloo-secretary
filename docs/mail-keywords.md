# 메일 선별 키워드

## 현재 설정

환경 변수 `MAIL_KEYWORDS`(쉼표 구분). 지금 값은 `학회`, `교수`다. Gmail 검색은 `newer_than:{기간}d ("학회" OR "교수")` 형태로 실행되고, 걸린 메일의 제목·보낸 사람·요약으로 중요도를 먼저 판단한 뒤 중요한 메일만 본문을 읽는다.

## 시험하는 방법

실제 메일로 키워드가 놓치면 곤란했던 메일을 잡는지 확인한다. 아래 명령은 **벨루에 쓰지도 카톡을 보내지도 않고** 처리 이력도 남기지 않으므로 몇 번이든 돌려도 된다. 메일 내용이 Gemini로 전송되니, 유료 등급 키로 돌린다.

```
npm run mail:dryrun -- --days 30
```

출력에서 볼 것:

1. **벨루에 추가될 후보**: 놓치면 곤란했던 메일(학회 마감, 교수님 요청 등)이 들어 있는가
2. **확인이 필요한 항목**: 마감일이 불확실하다고 표시된 메일. 지어내지 않고 사람이 보게 하는 항목이다
3. **중요하다고 본 메일 수 / 키워드에 걸린 메일 수**: 거의 다 중요하다고 나오면 키워드가 너무 좁고, 거의 다 아니라고 나오면 너무 넓다

## 키워드 조정 기준

- 놓친 메일이 있으면, 그 메일의 제목이나 보낸 사람에서 공통 단어를 키워드로 추가한다(예: 학회 이름, 학과 약칭, `Call for Papers`, `마감`).
- 광고가 많이 걸리면 키워드를 더 구체적으로 줄인다. 광고는 1차 판단에서 거르지만, 걸리는 메일이 많으면 모델 호출이 늘어난다.
- 조회 기간은 기본 2일이다. 이미 본 메일은 다시 판단하지 않으므로, Cron이 하루 빠져도 놓치지 않게 넉넉하게 잡은 값이다.
