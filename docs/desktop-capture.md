# PC에서 캡처로 입력하기

연구실 PC처럼 폰을 꺼내기 번거로울 때, 브라우저에서 캡처나 글 한 줄을 붙여넣으면 아이폰 단축어와 같은 경로로 접수된다. 설치할 것은 없다.

- 주소: `https://cap.2joon.com` (북마크해 두면 편하다). 같은 서비스라 `https://personal-secretary-kappa.vercel.app`로도 열린다.
- 결과는 아이폰 입력과 같이 **카톡 "나에게 보내기"** 로 온다. 이 페이지에는 결과가 뜨지 않고 "접수했습니다"만 뜬다.

## 사용법

1. 처음 한 번, 위 주소를 열고 `Win+Shift+S`로 **필요한 영역만** 캡처한다.
2. 페이지에서 `Ctrl+V`를 누른다. 처음에는 비밀값(`INTAKE_SECRET`)을 묻는다. 입력하면 이 브라우저에 저장되고, 보류했던 캡처가 이어서 전송된다.
3. "접수했습니다. 결과는 카톡으로 갑니다."가 뜨면 끝이다. 카톡의 `[비서] …`에서 읽은 내용과 만들어진 태스크를 확인한다.

글 한 줄은 입력창에 쓰고 `Enter`를 누른다. 줄바꿈은 `Shift+Enter`다. 접수되면 입력창이 비워지고, 실패하면 쓴 내용이 남는다.

## 동작

- 캡처는 가로 **1600px 이하 JPEG**로 줄여서 보낸다. 더 작은 캡처는 확대하지 않는다. (요청 본문 한도 4.5MB보다 훨씬 작다.)
- 전송 중에 다시 붙여넣거나 Enter를 누르면 "앞의 전송이 끝나면 다시 시도해 주세요"가 뜨고 새로 보내지 않는다.
- 한글을 입력하는 도중(글자 조합 중)의 `Enter`는 전송하지 않는다.
- 이미지도 글도 아닌 것(파일 등)을 붙여넣으면 안내만 나오고 전송하지 않는다.
- 서버가 인증을 거부하면 저장된 비밀값을 지우고 다시 입력받아 같은 내용을 보낸다.
- 브라우저가 값을 저장하지 못하는 환경(시크릿 모드, 정책 차단)에서는 그 사실을 알리고 이번 한 번은 입력한 값으로 보낸다. 이때는 매번 입력해야 한다.

## 주의할 점

- **비밀값이 이 브라우저에 저장된다.** 기관 PC라면 관리자나 보안 프로그램이 볼 수 있다. 여러 사람이 쓰는 PC에서는 쓰지 않는다. 이 비밀값으로 할 수 있는 일은 태스크를 **추가**하는 것뿐이고(수정·삭제 도구가 없다), 유출됐을 때의 영향은 스팸 태스크와 Gemini 호출 비용이다.
- **캡처한 화면의 내용이 Gemini로 전송된다.** 미공개 연구 결과, 학생 정보, 메신저 알림이 같이 찍히지 않게 영역 캡처를 쓴다. 기관의 보안 규정이 있으면 먼저 확인한다.
- 같은 서버를 폰 단축어도 쓰므로, 비밀값을 바꾸면 폰 단축어도 같이 바꿔야 한다(아래).

## 비밀값을 바꿀 때

1. `.env.local`의 `INTAKE_SECRET`을 새 값으로 바꾼다.
2. Vercel 값을 바꾸고 다시 배포한다.
   ```
   vercel env add INTAKE_SECRET production --sensitive --force
   vercel deploy --prod
   ```
3. 폰 단축어의 `Authorization` 헤더 값을 새 값으로 바꾼다([`shortcut.md`](shortcut.md)).
4. 이 페이지는 다음 전송에서 401을 받으면 저장값을 지우고 다시 묻는다. 먼저 지우려면 브라우저의 사이트 데이터를 지운다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 페이지가 안 열린다 | 연구실 네트워크가 막고 있을 수 있다. `cap.2joon.com`과 `vercel.app` 주소를 둘 다 열어 보고, 안 되면 다른 네트워크(폰 핫스팟)에서 열어 본다 |
| "인증에 실패했습니다" | 비밀값이 서버와 다르다. 다시 입력한다 |
| "접수했습니다"가 떴는데 카톡이 안 온다 | 서버 처리나 카톡 전송이 실패한 것이다. 다음 아침 보고의 `⚠ 실패:`와 [`operations.md`](operations.md)의 "실패가 보이는 곳"을 본다 |
| "서버 오류(…)" | 서버나 일시적인 장애다. 같은 내용을 다시 보내도 같은 이름과 마감의 태스크는 중복으로 만들어지지 않는다 |
| 붙여넣었는데 아무 일도 없다 | 페이지가 열린 탭에서 `Ctrl+V` 했는지 본다. 이미지도 글도 아닌 것을 붙여넣으면 "이미지나 글만 붙여넣을 수 있습니다"가 뜬다 |

## 개발자용

- 파일: `public/index.html`(화면과 이벤트 연결, 도메인 루트에서 열린다), `public/capture-lib.js`(크기 계산, 요청 본문, 응답 해석, 비밀값 저장 같은 순수 로직). 서버(`api/`, `src/`)는 바뀌지 않았다.
- 테스트: `tests/public/capture-lib.test.ts`. `tests/structure.test.ts`가 `public/`의 JS마다 테스트가 있는지 확인한다.
- `cap.2joon.com`은 DNS의 CNAME이 이 Vercel 프로젝트(`personal-secretary-kappa.vercel.app`)를 가리키고, 프로젝트에 `vercel domains add cap.2joon.com personal-secretary`로 연결했다. HTTPS 인증서는 Vercel이 자동으로 발급하고 갱신하므로 certbot이나 nginx 설정은 필요 없다(집 서버의 `veloo.2joon.com`과는 별개다).
- 같은 Vercel 프로젝트의 정적 파일이라 페이지와 `/api/intake`가 같은 출처다. 새 도메인에서도 `/api/intake`가 같은 출처로 응답한다. 그래서 CORS 설정이 필요 없다. 다른 도메인이나 로컬 파일에서 열면 사전 요청이 401로 막힌다.
- 로컬에서 화면만 볼 때는 `public/`에서 `python3 -m http.server 8765`로 띄운다. `/api`가 없어서 전송은 404가 되고, 아무것도 만들어지지 않는다.
- 배포는 `vercel deploy --prod`(GitHub 푸시로는 배포되지 않는다).
