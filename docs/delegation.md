# 위임 정책

비서가 어디까지 알아서 하고 어디서부터 확인이 필요한지를 단계로 나눈 목록이다. 코드의 `src/domain/policy.ts`와 같은 내용이어야 하며, `src/domain/policy.test.ts`가 둘을 대조한다. 행동을 추가하거나 단계를 바꿀 때는 이 문서와 코드를 함께 고친다.

## free (자유)

읽기·요약·초안 작성. 장부나 외부에 아무것도 바꾸지 않는다.

- `read_tasks`: 벨루 태스크 읽기
- `search_mail`: 메일 목록 검색(제목·발신자·요약)
- `read_mail_body`: 메일 본문 읽기

## notify (알리고 수행)

실행하고, 다음 보고에 반드시 포함한다.

- `create_task`: 벨루에 태스크 추가(메모에는 내용만 쓴다)

## confirm (확인 후 수행)

승인 전에는 실행하지 않는다. 호출하면 제안으로만 기록되고, 다음 보고에 제안으로 실린다. 실제 수정은 사용자가 벨루에서 직접 한다.

- `update_task`: 기존 태스크 수정
- `delete_task`: 기존 태스크 삭제

## forbidden (금지)

수행할 도구 자체를 제공하지 않는다. 모델이 요청받아도 할 수 없다.

- `send_mail`: 메일 발송
- `submit_external`: 외부 제출
- `make_payment`: 금전 지출
