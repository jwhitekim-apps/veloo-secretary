# Spec Delta

## Purpose
윈도우 PC의 브라우저에서 캡처 이미지나 글 한 줄을 붙여넣기만 해서 비서의 입력 엔드포인트로 접수하게 한다. 폰의 단축어를 대신하는 입력 경로다.

## ADDED Requirements

### Requirement: 입력 페이지를 비서와 같은 주소에서 제공한다
시스템 SHALL 비서 서버와 같은 도메인에서 로그인 없이 열 수 있는 입력 페이지를 제공한다. 페이지 자체에는 비밀값이 들어 있지 않아야 한다.

#### Scenario: 페이지 열기
- **WHEN** 브라우저에서 입력 페이지 주소를 연다
- **THEN** 404가 아니라 입력 페이지가 보인다

#### Scenario: 도메인 주소만 입력
- **WHEN** 파일 이름 없이 도메인 주소(`/`)만 연다
- **THEN** 입력 페이지가 보인다

#### Scenario: 검색에 노출되지 않음
- **WHEN** 검색 엔진이 페이지를 수집하려 한다
- **THEN** 페이지는 색인하지 말라는 표시를 담고 있다

### Requirement: 붙여넣은 캡처를 줄여서 접수한다
시스템 SHALL 페이지에 붙여넣은 이미지를 요청 본문 한도(4.5MB)보다 훨씬 작은 JPEG로 줄여서 기존 입력 주소에 비동기 접수 모드로 보낸다.

#### Scenario: 큰 화면 캡처
- **WHEN** 가로 2560px짜리 PNG 캡처를 붙여넣는다
- **THEN** 가로 1600px 이하의 JPEG로 변환되어 전송되고 요청 본문은 1MB를 넘지 않는다

#### Scenario: 이미 작은 캡처
- **WHEN** 가로 800px짜리 캡처를 붙여넣는다
- **THEN** 확대하지 않고 원래 크기를 유지한 채 JPEG로 전송된다

#### Scenario: 이미지가 아닌 것을 붙여넣음
- **WHEN** 이미지도 글도 아닌 내용을 붙여넣는다
- **THEN** 전송하지 않고 무엇을 붙여넣을 수 있는지 안내한다

### Requirement: 글 한 줄을 접수한다
시스템 SHALL 입력창에 쓴 글을 Enter로 같은 입력 주소에 보낸다.

#### Scenario: 한 줄 입력
- **WHEN** 입력창에 "내일까지 보고서 제출"을 쓰고 Enter를 누른다
- **THEN** 글이 접수되고 입력창이 비워진다

#### Scenario: 빈 입력
- **WHEN** 아무것도 쓰지 않고 Enter를 누른다
- **THEN** 아무것도 전송하지 않는다

### Requirement: 비밀값은 처음 한 번만 묻는다
시스템 SHALL 비밀값을 처음 사용할 때 한 번 입력받아 그 브라우저에 저장하고, 이후에는 다시 묻지 않는다. 서버가 거부하면 저장된 값을 버리고 다시 입력받는다.

#### Scenario: 첫 사용
- **WHEN** 저장된 비밀값이 없는 상태에서 무언가를 보낸다
- **THEN** 비밀값을 입력받고, 입력한 값으로 같은 내용을 전송한다

#### Scenario: 저장된 값 사용
- **WHEN** 저장된 비밀값이 있는 상태에서 무언가를 보낸다
- **THEN** 다시 묻지 않고 전송한다

#### Scenario: 비밀값이 바뀌어 거부됨
- **WHEN** 서버가 인증 실패로 응답한다
- **THEN** 저장된 값을 지우고 다시 입력받으며, 인증 실패라고 알린다

#### Scenario: 저장소를 쓸 수 없음
- **WHEN** 브라우저가 값을 저장하지 못한다
- **THEN** 이번 한 번은 입력한 값으로 보내고, 매번 물을 수 있음을 알린다

### Requirement: 접수 결과와 오류를 화면에 알린다
시스템 SHALL 전송 중, 접수됨, 실패를 화면에 구분해서 보여 주고, 전송이 끝나기 전에는 같은 내용을 다시 보내지 않는다.

#### Scenario: 정상 접수
- **WHEN** 서버가 접수했다고 응답한다
- **THEN** 접수되었고 결과는 카톡으로 간다는 문구를 보여 준다

#### Scenario: 서버 오류나 네트워크 오류
- **WHEN** 전송이 실패한다
- **THEN** 실패했다는 사실과 이유를 보여 주고 같은 내용을 다시 보낼 수 있게 한다

#### Scenario: 연속 붙여넣기
- **WHEN** 앞의 전송이 끝나기 전에 다시 붙여넣는다
- **THEN** 앞의 전송이 끝날 때까지 새 전송을 시작하지 않는다

### Requirement: 기존 입력 경로를 바꾸지 않는다
시스템 SHALL 이 페이지를 추가해도 아이폰 단축어가 쓰는 입력 요청의 형식과 응답을 그대로 유지한다.

#### Scenario: 기존 단축어 요청
- **WHEN** 기존 단축어가 JSON `text` 또는 `image` 요청을 보낸다
- **THEN** 이전과 같은 응답과 처리 결과를 받는다
