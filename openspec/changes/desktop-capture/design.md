# Design

## Context

서버의 입력 엔드포인트는 `POST /api/intake`에 `Authorization: Bearer <비밀값>`과 JSON(`{"text": ...}` 또는 `{"image": "<base64>", "mimeType": ...}`)을 받는다. `mimeType`을 생략하면 JPEG로 본다. `?async=1`이면 바로 접수를 돌려주고 결과는 카톡으로 보내며, `?format=text`면 평문으로 응답한다. 요청 본문은 Vercel 한도(4.5MB)가 있어 폰 단축어는 가로 1000px JPEG로 줄여서 보냈다. 프로젝트에는 지금 `api/` 함수만 있고 정적 파일은 없다. 동기는 proposal.md의 Why를 본다.

## Goals / Non-Goals

**Goals:**
- 설치 없이 브라우저만으로 캡처 한 번에 접수한다.
- 서버 코드는 바꾸지 않는다.
- 이미지 축소처럼 틀리기 쉬운 계산은 노드 테스트로 검증한다.

**Non-Goals:**
- PC 전용 별도 비밀값, 로그인, 벨루 백엔드 경유. 필요해지면 후속 변경으로 한다.
- 접수 뒤의 결과 표시. 결과는 기존대로 카톡으로 간다.
- 브라우저 확장, 앱 설치, 전역 단축키.

## Decisions

### 1. 같은 Vercel 프로젝트의 정적 페이지로 둔다
`public/` 아래에 두어 비서와 같은 출처에서 서빙한다. 같은 출처라서 브라우저의 CORS 사전 요청이 없고(현재 서버는 `OPTIONS`에 401을 돌려줘 다른 출처에서는 막힌다) 서버를 고칠 필요가 없다. 대안은 로컬 HTML 파일이나 다른 도메인이지만 그러면 서버에 CORS 응답을 추가해야 한다.

### 2. 페이지와 순수 로직을 두 파일로 나눈다
`public/index.html`(결정 7)은 화면과 이벤트 연결만 한다. 크기 계산, 요청 본문 만들기, 응답 해석처럼 틀리기 쉬운 부분은 `public/capture-lib.js`(브라우저에서 바로 실행되는 일반 ES 모듈)로 빼서 노드 테스트로 검사한다. 빌드 단계를 추가하지 않는다.

### 3. 이미지는 가로 1600px 이하 JPEG로 줄인다
캔버스에 다시 그려 JPEG(품질 0.85)로 내보낸다. 원본이 더 작으면 확대하지 않는다. 폰은 1000px로 충분했지만 데스크톱 캡처는 글자가 작아서 약간 여유를 둔다. 앞선 손글씨 실험에서 해상도보다 모델이 중요했으므로 이 크기로 시작하고, 읽기 어려우면 값만 조정한다.

### 4. 기존 접수 모드를 그대로 쓴다
`/api/intake?async=1&format=text`로 보낸다. 서버는 바로 접수를 알려 주고 결과를 카톡으로 보내므로, 폰과 같은 확인 경로를 쓴다.

### 5. 비밀값은 브라우저 `localStorage`에 둔다
처음 한 번 입력받고 저장한다. 저장소에 접근할 수 없는 환경(시크릿 모드, 정책 차단)에서도 페이지는 동작해야 하므로 읽기와 쓰기를 모두 예외 처리하고, 그때는 매번 묻는다. 서버가 401을 주면 저장값을 지운다.

### 6. 구조 테스트의 "짝 없는 테스트" 규칙을 `public/`까지 넓힌다
지금은 `tests/` 아래 모든 테스트가 `src/`의 같은 경로 소스와 짝이어야 한다. `public/`의 로직 테스트는 `tests/public/`에 두고, 그 경로는 `public/`의 파일과 짝을 맞춘다. 브라우저용 JS를 노드 테스트에서 가져오려면 타입 검사 설정에서 JS 가져오기를 허용해야 할 수 있다.

### 7. 입력 페이지는 도메인 루트(`/`)에서 연다
`cap.2joon.com`이라는 도메인 이름이 이미 캡처 입력을 뜻하므로 `/capture.html`은 같은 말의 반복이다. 페이지를 `public/index.html`로 두어 설정 없이 루트에서 서빙한다. 같은 프로젝트의 `vercel.app` 루트도 입력 페이지가 되지만 페이지에는 비밀값이 없고 인증은 서버가 하므로 문제 없다. 옛 주소 `/capture.html`은 아직 쓰기 전이라 리다이렉트 없이 없앤다. 대안은 `vercel.json`의 rewrite로 `/`를 옛 파일에 연결하는 것이지만 설정이 늘어난다. 스크립트 `public/capture-lib.js`는 주소와 무관한 내부 파일이라 이름을 유지한다.

## Risks / Trade-offs

- **비밀값이 기관 PC 브라우저에 남는다.** 관리자나 보안 프로그램이 볼 수 있다. 쓰기 범위는 태스크 추가뿐이라 영향은 스팸 태스크와 Gemini 비용이다. 의심되면 `INTAKE_SECRET`을 바꾸고(폰 단축어도 같이 바꿔야 한다) 후속으로 PC 전용 비밀값을 만든다.
- **정적 파일 서빙이 지금 구성에서 되는지 모른다.** 프로젝트에 `api/`만 있고 빌드 설정이 없다. 첫 작업에서 자리표시 페이지로 먼저 확인하고, 안 되면 `vercel.json` 설정을 조정한다.
- **기관 네트워크가 `vercel.app`을 막을 수 있다.** 설계로 풀 수 없고 실제 연구실에서 열어 봐야 안다.
- **화면 전체 캡처의 내용이 Gemini로 나간다.** 영역 캡처를 쓰도록 문서에 적는다. 기관 보안 규정은 사용자가 판단한다.
