# Proposal

## Why

연구실 PC에서 작업하다 일이 생겼을 때 벨루를 열어 필드를 채우는 일은 번거롭고, 아이폰 단축어는 폰을 꺼내야 한다. 비서 서버는 이미 글과 이미지를 받지만, 윈도우 PC에서 보낼 방법이 없다. 주소를 열면 화면이 없어 404이고, Postman은 이미지를 base64로 바꿔 주지도 크기를 줄여 주지도 않아 매번 쓰기 어렵다.

## What Changes

- 비서 서버와 **같은 Vercel 주소**에서 입력 페이지를 제공한다. 같은 출처라서 CORS 설정이 필요 없고 서버 코드는 바꾸지 않는다.
- 페이지에서 `Win+Shift+S`로 찍은 캡처를 `Ctrl+V`로 붙여넣으면 자동으로 줄이고 JPEG로 바꿔서 기존 입력 주소(`/api/intake?async=1&format=text`)로 보낸다. 결과는 아이폰 입력과 같이 카톡으로 온다.
- 같은 페이지의 입력창에 글 한 줄을 쓰고 Enter를 눌러도 보낸다.
- 인증 비밀값은 처음 한 번만 물어보고 브라우저에 저장한다.
- 기존 아이폰 단축어 요청과 서버의 입력 형식은 바꾸지 않는다.
- **범위 밖**: PC 전용 별도 비밀값, 로그인, 벨루 백엔드를 거치는 방식, 단축키 설치형 프로그램, 음성 입력.

## Capabilities

### New Capabilities
- `desktop-capture`: 윈도우 브라우저에서 캡처 이미지나 글 한 줄을 붙여넣어 비서의 입력 엔드포인트로 접수하는 입력 페이지.

## Impact

- 새 파일: `public/` 아래 정적 페이지와 브라우저에서 쓰는 순수 로직 파일, 그 테스트, 사용 문서.
- 기존 서버(`api/`, `src/`)는 바뀌지 않는다. 정적 파일이 Vercel에서 서빙되는지 확인이 필요하다(현재는 `api/`만 있다).
- 보안: 비밀값이 연구실 PC 브라우저 저장소에 남는다. 쓰기 범위는 태스크 추가뿐이고(수정·삭제 도구 없음), 유출 시 영향은 스팸 태스크와 Gemini 호출 비용으로 한정된다.
- 개인정보: 캡처한 화면의 내용이 Gemini로 전송된다. 영역 캡처로 필요한 부분만 보내는 습관이 필요하다.
