# Spec Delta

## ADDED Requirements

### Requirement: 음성 받아쓰기로 들어온 입력임을 표시할 수 있다
시스템은 입력 요청이 음성 받아쓰기 결과임을 알리는 표시를 받을 수 있어야 한다(SHALL). 표시가 있으면 이름과 장소 같은 고유명사가 잘못 인식되었을 수 있다고 보고, 의심스러운 부분은 고쳐 쓰지 않고 보이는 그대로 두며 추정으로 알려야 한다(SHALL). 의심스러운 부분이 없으면 오인식 안내를 붙이지 않아야 한다(SHALL NOT). 알 수 없는 표시 값은 무시해야 하고(SHALL), 표시가 없을 때와 처리 경로, 저장 규칙, 응답 형식은 같아야 한다(SHALL).

#### Scenario: 어색한 이름이 섞인 받아쓰기
- **WHEN** 음성 표시와 함께 "다음 주 화요일 오후 3시 램미팅 삼공학관"이 들어온다
- **THEN** 일정은 평소처럼 추출되고 이름은 받아쓴 그대로 쓰이며, 추정에 받아쓰기 오인식 가능성이 짧게 알려진다

#### Scenario: 어색한 부분이 없는 받아쓰기
- **WHEN** 음성 표시와 함께 "금요일까지 교수님 메일 답장"이 들어온다
- **THEN** 일정은 평소처럼 추출되고 오인식 안내는 붙지 않는다

#### Scenario: 알 수 없는 표시 값
- **WHEN** 표시 값이 `voice`가 아닌 다른 값이다
- **THEN** 표시가 없는 것처럼 처리한다

#### Scenario: 표시가 없는 입력
- **WHEN** 표시 없이 입력이 들어온다
- **THEN** 이전과 같은 방식으로 해석하고 같은 응답을 돌려준다
